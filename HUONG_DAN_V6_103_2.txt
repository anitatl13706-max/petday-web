CHAY LOCAL
1. Giai nen ZIP -> PETDAY_OFFICIAL.
2. Sao chep server/.env an toan tu ban cu; KHONG dua file .env len Git.
3. Dung frontend va backend cu bang Ctrl+C.
4. Terminal 1: cd PETDAY_OFFICIAL/server ; npm install ; npm start
5. Terminal 2: cd PETDAY_OFFICIAL ; npm install ; npm run dev
6. Mo dia chi Vite in ra; refresh Ctrl+F5.

2. Tim yeu cau co ngay de nghi 2026-12-05, trang thai Da duyet.
3. Neu 'Lich hen hien tai' la 2026-12-04, bam 'Dong bo lich da duyet'.
